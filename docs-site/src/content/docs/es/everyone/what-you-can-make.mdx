Si lo podés describir, lo podés hacer. Acá hay cosas reales que la gente publica con ShareOut — robate cualquiera como punto de partida.

## Para tu negocio

<CardGrid>
	<Card title="🥐 Un menú siempre actualizado">
		*"Una página para mi café con el menú del día, los horarios y un mapa."* Cambiá un precio en segundos — sin reimprimir, sin app store.
	</Card>
	<Card title="🛍️ Una tiendita online">
		*"Una página para vender mis velas, con fotos, precios y una forma de pedir."* Ideal para un emprendimiento o un puesto de feria.
	</Card>
	<Card title="💇 Una página de turnos">
		*"Una página donde mis clientes vean mis servicios y pidan un turno."* Se ve profesional, no cuesta nada, vive en su propio link.
	</Card>
	<Card title="📋 Una lista de precios">
		*"Una página limpia con lo que ofrezco y cuánto sale."* Mandá el link en vez de un PDF desprolijo.
	</Card>
</CardGrid>

## Para un evento

<CardGrid>
	<Card title="💍 Una página de casamiento con RSVP">
		*"Una página para nuestro casamiento — la fecha, el lugar y un formulario para que los invitados confirmen."* Juntá todas las respuestas en un solo lugar.
	</Card>
	<Card title="🎉 Una invitación de cumple">
		*"Una invitación para el cumple de mi hija con los datos y un 'quién viene'."* Mandá el link al grupo de WhatsApp.
	</Card>
	<Card title="🎟️ Inscripción a un taller o clase">
		*"Una página para mi taller de cerámica de los sábados donde la gente reserve un lugar."* Compartila en tu grupo de la comunidad.
	</Card>
</CardGrid>
