## Tu idea, en vivo en *tu* instancia

ShareOut es **solo self-hosted**. Alguien lo despliega en Cloudflare; después
describís una página, la arma, y tenés un link en tu dominio.

<CardGrid stagger>
	<Card title="Primero instalá">
		Cloná el repo, `npm run deploy`, abrí `/setup`. [Guía de install](/es/self-host/overview/).
	</Card>
	<Card title="Solo describilo">
		Decile a ShareOut qué querés — *"una página para mi panadería con el menú y un formulario"* — y la arma. [Hacé tu primera página](/es/everyone/make-your-first-page/).
	</Card>
	<Card title="Hacela tuya">
		Sumá fotos, cambiá textos y colores, agregá un formulario. Clic o pedilo. [El editor](/es/everyone/the-editor/).
	</Card>
	<Card title="Compartila">
		Cada página tiene su link. Al mundo, o a pocas personas. [Compartila](/es/everyone/share-it/).
	</Card>
</CardGrid>
