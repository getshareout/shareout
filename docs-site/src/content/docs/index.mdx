## Start here — no technical knowledge needed

Everything you make in ShareOut — a table, a report, a dashboard, a small website — is a **page
with its own link** (ShareOut also calls it an *artifact*). You decide who can open it.

## Where you use ShareOut

- **ShareOut Cloud** at [shareout.site](https://shareout.site) — new accounts are by invitation for now.
- **Your company's own ShareOut** — ask whoever set it up for the address. The guides work the same.
- **Setting one up yourself?** It runs on your own Cloudflare account: [install guide](/self-host/overview/).
