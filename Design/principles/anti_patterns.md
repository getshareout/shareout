# Anti-Patterns

Never do these. They're the "tell" of generic AI design or legacy enterprise software.

---

## Visual

| Don't | Do Instead |
|-------|------------|
| Purple gradients | Solid, intentional blue + warm neutrals |
| Inter/Roboto everywhere | Distinctive, readable font pairing |
| Thin gray text on white | High contrast, warm tones |
| Cold / blue-gray glassmorphism | Warm liquid glass that builds depth & hierarchy |
| Cold blue-gray UI chrome | Warm stone/cream backgrounds |
| Rainbow palettes | 80% neutral, 5% blue |
| Crypto / AI startup gradients | ShareOut Blue used sparingly |
| Dark mode as afterthought | Designed dark mode or none |

---

## Interaction

| Don't | Do Instead |
|-------|------------|
| Icons without labels | Words first, icons support |
| Hover effects on everything | Motion with purpose |
| Hover-only info | Visible on touch devices |
| Icon-only buttons for key actions | Icon + label always |
| Multiple competing CTAs | One clear action per surface |
| "Get Started" as only CTA | Specific: "Create Page" |
| Bounce, spin, elastic animation | Reveal, fade, guide attention |
| Scroll-jacking | Respect user control |

---

## Content & Layout

| Don't | Do Instead |
|-------|------------|
| Feature lists with checkmarks | Show, don't list |
| Cards in a perfect grid with no hierarchy | Layouts with clear hierarchy |
| Feature overload (47 equal options) | One thing at a time |
| Jargon ("Deploy artifact") | Plain language ("Share your page") |
| Cluttered pitch-deck density | Generous spacing |

---

## Content & Sample Data

The fastest "this was auto-generated" tell. Applies to UI placeholders, marketing examples, demos, screenshots.

| Don't | Do Instead |
|-------|------------|
| "John Doe" / "Jane Smith" placeholders | Real, varied, locale-appropriate names |
| "Acme" / "Nexus" / "SmartFlow" brands | Contextual names that sound real |
| Fake-round numbers (`50%`, `99.99%`, `1,234,567`) | Organic data (`47.2%`, `$99.00`, `1,284`) |
| Lorem ipsum | Real copy, even if short |
| Identical dates on every demo item | Varied, realistic dates |
| Generic avatar eggs / same photo repeated | Distinct, believable avatars |
| AI clichés: "Elevate", "Seamless", "Unleash", "Next-Gen", "Revolutionize", "Game-changer", "Delve" | Concrete verbs (see [../brand/voice.md](../brand/voice.md)) |

---

## Brand & Logo

| Don't | Do Instead |
|-------|------------|
| Microsoft / legacy enterprise visual language | Figma / Miro / Canva creative-tool energy |
| Literal clip-art (clouds, chains, robots) | Abstract, ownable geometry |
| Chain links (overused "share") | Frame, portal, transformation metaphors |
| Overly playful / childish mascots | Warm but capable |
| AI robots, sparkles, generic orbs | Modern tool-like, not AI-hype |

---

## Explicitly Avoid Resembling

Microsoft · PowerBI · SharePoint · Legacy BI (Tableau chrome, Looker gray) · Enterprise software aesthetics · Stock handshakes · Fake diversity photos
