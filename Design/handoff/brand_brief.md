## Executive Summary

**ShareOut** is an agentic-first publishing platform. Users (or AI agents) build anything — dashboards, decks, micro-apps, RSVP pages, finance trackers, pitch decks — and publish live to the web in one click.

The brand should feel **easy, fast, and powerful** — like Miro, Figma, and Canva — never like Microsoft or legacy enterprise software.

**Deliverable ask:** A distinctive **symbol** (works at favicon/app-icon size) plus wordmark, color system anchored in **blue**, typography pairing, and basic usage rules for product UI and marketing.

## Logo Direction

**Symbol-first identity** — see [../visual/logo.md](../visual/logo.md) for full spec.

### What "agentic first" means for the mark

The logo should feel **native to how software is built now** (humans + agents creating together) — modern, fast, tool-like — without screaming "AI product." Think Figma's evolution, not ChatGPT's sparkle.

## Open Questions for Designer

1. **Symbol concept** — Which metaphor wins? (share-outward vs live-publish vs canvas-create vs abstract)
2. **Wordmark** — Custom letterforms vs existing display font?
3. **Display typography** — Keep Instrument Sans or new recommendation?
4. **Tagline** — Propose 2–3 options from [../brand/positioning.md](../brand/positioning.md)
5. **Enterprise co-branding** — How symbol sits next to customer logos on subdomains
6. **Dark mode mark** — Single reversed treatment or separate dark-optimized symbol?
