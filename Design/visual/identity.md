# Visual Identity

## Visual Philosophy

ShareOut should look like **possibility**.

Not software. Not dashboards. Not reports.

Every visual decision should reinforce the transformation from idea to reality.

The visual system should feel like:

- A blank canvas becoming alive
- A doorway opening
- A possibility becoming reality
- A frame waiting to be filled
- A creative tool

Never a file manager. Never an analytics dashboard. Never a corporate portal.

---

## The Big Idea: From Idea to Live

Everything in the visual system should support this concept.

An idea becomes reality. A thought becomes a thing. A concept becomes something people can interact with.

The visual identity represents **transformation**.

## Material: Liquid Glass

The product UI is built as **one unified canvas with translucent surfaces floating on top.** A single warm gradient runs underneath everything; rail, hero, cards, and panels are glass that lets the canvas show through, layered with soft inner highlights and depth shadows.

This is glass *as structure* — it organizes hierarchy and depth, not surface sparkle. Guardrails:

- **Warm, never cold.** Translucent warm-white over the canvas — never blue-gray glass.
- **Contrast holds.** Text stays warm-black and fully legible; inputs, modals, and dialogs may stay opaque when glass would hurt readability.
- **Restraint.** The blue accent rule still applies — glass is the neutral material, not a color event.

Implemented via the `--glass-*` tokens in `design-system/pages/home.css.ts`.

## Explicitly Avoid

Microsoft · PowerBI · SharePoint · Enterprise software aesthetics · AI startup gradients · Crypto branding · Cold / trend-chasing glassmorphism (blue-gray, low-contrast, decorative)
